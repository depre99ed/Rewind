Les nouvelles versions te sont proposées dès le lancement.

- Au démarrage, une petite fenêtre annonce la mise à jour s'il y en a une : tu mets à jour, ou tu continues.
- Sinon, Rewind s'ouvre normalement, sans attendre.
- L'enregistrement démarre dans tous les cas.

---

New versions are offered as soon as you start Rewind.

- At startup, a small window announces the update if there is one: update now, or carry on.
- Otherwise, Rewind opens as usual, without waiting.
- Recording starts either way.
