Un démarrage réduit qui ne cache plus les mises à jour, et un démarrage avec Windows plus fiable.

- Démarrage réduit ou lancement par Windows : s'il y a une mise à jour, la petite fenêtre s'ouvre ; sinon Rewind reste discret.
- « Plus tard » ferme la fenêtre sans ouvrir Rewind.
- Le démarrage avec Windows vise toujours la version installée, même après une mise à jour.

A minimized start no longer hides updates, and starting with Windows is more reliable.

- Minimized start or launch by Windows: if an update exists, the small window opens; otherwise Rewind stays discreet.
- "Later" closes the window without opening Rewind.
- Starting with Windows always targets the installed version, even after an update.
