Rewind se lance en administrateur : F8 et les touches à l'écran marchent dans tous les jeux.

- Au premier lancement, Windows demande une fois l'autorisation ; ensuite Rewind démarre en administrateur tout seul, même avec Windows.
- Indispensable quand Steam ou le jeu tourne en administrateur : sinon Windows cache les touches du jeu à Rewind.
- Réglable dans Réglages › Raccourcis › Lancer Rewind en administrateur.

---

Rewind now runs as administrator: F8 and on-screen keys work in every game.

- On first launch, Windows asks once; then Rewind starts as administrator on its own, even with Windows.
- Needed when Steam or the game runs as administrator: otherwise Windows hides the game's keys from Rewind.
- Can be changed in Settings › Hotkeys › Run Rewind as administrator.
