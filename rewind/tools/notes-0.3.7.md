More reliable Studio and fewer antivirus false alarms.

- Fixed: the Projects menu could be covered by the preview (dark "clip not found" frame).
- Fixed: during playback, the start of the edit slid under the "Video" label and you could not get back to it. The timeline now follows the playhead both ways, and the mouse wheel scrolls the timeline sideways.
- Missing project thumbnail (moved clip): an icon instead of a broken image.
- Fewer antivirus false alarms: the voice command now runs inside Rewind (same Windows engine, same settings) instead of a hidden PowerShell script; no more cmd, ping or reg.exe started in the background.
