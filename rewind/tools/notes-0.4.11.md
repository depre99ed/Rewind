Lighter and more reliable Rewind, with no change to your clip quality.

- Recording comes first: when the PC is maxed out, the capture keeps every frame. Side tasks (thumbnails, receiving friends' clips, editing) wait or only take what the game leaves.
- Less memory: the background-removal tool is released 2 minutes after use, the memory buffer no longer copies every second twice, and a full session kept in memory can no longer fill the PC's RAM.
- Window minimized or behind the game: the interface goes to sleep (animations, featured video, refreshes). In the foreground, nothing changes.
- More reliable: the last second is no longer lost when the capture restarts, Studio export falls back to the processor if the graphics card refuses, and temporary files are cleaned up automatically.
